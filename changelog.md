# Changelog

All notable Lyric Solitaire development changes are recorded here.

## [0.1.1] — 2026-09-02

### Added
- Complete individual-trial collections in simulator exports.
- `allWordsUsedTrials`, `allWordsUsedRate`, and `everAllWordsUsed` tracking.
- First-generation `results.html` for file-based experiment comparison and histograms.
- Central simulator-version display and versioned experiment records.
- Experiment metadata sufficient to reproduce rule settings.

### Fixed
- Standard and Hard now use their intended row, hand-limit, and maximum-round settings.
- Starting a new simulation automatically clears prior displayed results; Reset is optional between tests.
- Seed progression is deterministic across trials for a given seed.

### Important Testing Note
- v0.1.0 experiments labeled Standard or Hard were generated by an Easy-only engine and should not be used as valid Standard/Hard difficulty evidence. Re-run those tests under v0.1.1.

## [0.1.0] — 2026-09-02

### Added
- Initial Simulator Lab release.
- Composite song catalog.
- Song statistics for total and unique words.
- Initial Simulator Lab visual identity.
