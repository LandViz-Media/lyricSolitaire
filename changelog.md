# Changelog

All notable Lyric Solitaire development changes are recorded here.

## [0.1.0] — 2026-09-02

### Added
- Established **Simulator v0.1.0** as the current simulator version.
- Added standardized simulator test-result JSON records.
- Added browser-side test history and JSON export support.
- Added `song_library/` as the planned maintained location for song data.
- Added a composite song catalog for application access to song metadata and file references.
- Added shared JavaScript version configuration so the simulator version can be changed without regenerating artwork.
- Added initial Simulator Lab header artwork.
- Added documentation structure for game rules and simulator development.

### Test Data
- Recorded the first Quittin' Time simulator test from the initial manual test run.

### Planned
- Expand simulator experiments across all available songs.
- Aggregate exported test results into a combined analysis file.
- Develop visual comparisons of song challenge characteristics.
- Develop a data-driven song difficulty model.

## Data Changelog

New songs discovered or added to the song library may be recorded here. The actual lyric and word-count JSON files remain maintained separately in `song_library/`.
