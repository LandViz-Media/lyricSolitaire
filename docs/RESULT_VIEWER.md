# Results Viewer

`results.html` is a developer tool for reviewing exported simulator experiments.

## Current capabilities

- Load multiple JSON experiment exports.
- Filter by song.
- Filter by mode.
- Filter by simulator version.
- Compare experiment-level win rate.
- Compare all-words-used rate.
- Inspect aggregate average words played.
- Plot a histogram from complete individual-trial data.

## Planned capabilities

- Song-by-song comparisons.
- Easy / Standard / Hard comparisons.
- Histograms for words played, rounds, completed lines, and final hand.
- Win/loss distributions.
- Simulator-version comparisons.
- Master test-results dataset generation.
- Challenge-level diagnostics and the eventual song difficulty algorithm.
