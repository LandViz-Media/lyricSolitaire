# Results Viewer

`results.html` is a developer tool for inspecting exported simulator experiment data.

## Current capabilities

- Load multiple experiment JSON files.
- Filter by song and mode.
- Compare experiment-level win rate and all-words-used rate.
- Inspect aggregate words-played values.
- Display a trial-level histogram when complete individual trials are present.

## Planned capabilities

- Song-by-song comparisons.
- Mode comparisons.
- Histograms for words played, rounds, completed lines, and final hand.
- Win/loss distributions.
- Simulator-version comparisons.
- A combined master test-results dataset.
- Challenge-level diagnostics and the eventual song difficulty algorithm.
